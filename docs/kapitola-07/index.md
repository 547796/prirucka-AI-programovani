Každá aktivita je strukturovaná takto:

1. **Cíl** – co žáci po aktivitě umí
2. **Postup** – krok za krokem
3. **Variace** – úpravy pro různé úrovně
4. **Hodnocení** – jak aktivitu zhodnotit
